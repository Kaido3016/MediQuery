# MediQuery — Step 8 Completion Checklist

## Objective

Turn the acquisition positioning into a concrete, prioritized buyer-targeting system.

## Completed

- [x] Defined buyer categories.
- [x] Created a prioritized strategic prospect list.
- [x] Separated strategic fit from actual buyer intent.
- [x] Defined decision-maker roles to contact.
- [x] Defined qualification signals.
- [x] Defined weak signals that must not be treated as acquisition interest.
- [x] Defined first-wave outreach.
- [x] Defined subsequent outreach waves.
- [x] Connected prospect tracking to `ACQUISITION_CONTACT_TRACKER.md`.
- [x] Added explicit disclosure that named organizations are prospective targets only.
- [x] Added a rule to refresh current company/leadership information immediately before outreach.

## Step 8 exit criteria

Step 8 is complete when a seller can answer:

1. Who should be contacted first?
2. Which executive roles should be targeted?
3. Why is each prospect strategically relevant?
4. What evidence qualifies a prospect as genuinely interested?
5. How will prospects be tracked without exposing confidential information?
6. How will the seller avoid unsupported acquisition or valuation claims?

All six questions are addressed by the buyer-target list, outreach playbook, and acquisition contact tracker.

## Next phase

The next phase should focus on converting the buyer-targeting system into an evidence-backed external acquisition package: current buyer research, verified corporate-development/contact routes, a polished executive one-pager, and a controlled data-room structure.
